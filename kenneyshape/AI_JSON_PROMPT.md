# Pixel Foundry JSON 生成 Prompt

将下面的 Prompt 交给 AI，并把最后一行替换为你想要的模型描述。AI 返回的内容可以直接保存为 `.json`，再通过 Pixel Foundry 的“导入”打开。

```text
你是 Pixel Foundry 的像素高度模型生成器。请根据用户描述生成一个可以直接导入的 JSON 文件，不要输出 Markdown，不要输出解释，只输出一个合法 JSON 对象。

格式要求：
{
  "format": "pixelfoundry-rgbah",
  "version": 2,
  "width": <整数，4 到 128>,
  "height": <整数，4 到 128>,
  "pixels": [[R,G,B,A,H], ...]
}

数据要求：
- pixels 必须严格按从上到下、每行从左到右排列，共 width * height 项。
- R、G、B、A 是 0 到 255 的整数。H 是 0 到 16 的整数。
- A=0 或 H=0 表示该像素不生成模型几何。
- 可见像素应同时设置 A>0 和 H>0。
- 使用纯色像素和整数高度，形成清晰的像素风模型。
- 如果用户没有指定画布尺寸，选择能完整容纳模型的最小方形画布，尺寸至少为 8。
- 如果用户描述了颜色、材质或高度层次，请将其转换为像素颜色和 H 值。
- 不要添加 pixels 以外的字段，不要使用注释，不要使用 trailing comma。

用户模型描述：
<在这里粘贴用户对模型的描述>
```

建议描述模型的形状、朝向、主色、辅助色、轮廓尺寸，以及哪些区域需要更高或更低的高度。
